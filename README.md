# AI 비서 🐾

화면 구석에 떠 있는 3D 캐릭터 비서. 체크메이트 일정을 알려 주고, 집중 타이머·건강 알림·물어보기를 해 줘요.

## 📥 설치

| 어디서 | 이렇게 |
| --- | --- |
| 📱 **안드로이드** | [릴리스 페이지](https://github.com/seoyulwoo1206/ai-biseo/releases/latest) 맨 아래 **Assets** 에서 `.apk` 받기 → 파일 열어서 설치 ("출처를 알 수 없는 앱" 허용) |
| 🍎 **아이폰** | 사파리로 https://ai-biseo-mocha.vercel.app → 공유 → **홈 화면에 추가** |
| 🌐 **설치 없이** | 아무 브라우저로 https://ai-biseo-mocha.vercel.app |
| 💻 **윈도우 PC** | [Node.js](https://nodejs.org) 설치 → 위쪽 초록 **Code** → **Download ZIP** → 압축 푼 폴더에서 `npm install` → `npm start` |
| 💻 **맥북** | [Node.js](https://nodejs.org) 설치 → 위쪽 초록 **Code** → **Download ZIP** → 압축 푼 폴더를 오른쪽 클릭 → **폴더에서 새로운 터미널** → `npm install` → `npm start` (아직 진짜 맥에선 안 켜 봤어요) |

설치한 뒤 캐릭터(폰은 ⚙️)를 눌러 **설정 → 로그인** 에서 체크메이트 계정으로 로그인하면 끝!

## 실행

```bash
npm install
npm start
```

처음 켜면 **컴퓨터 켤 때 자동 실행**이 켜져요. (설정 → 기타에서 끌 수 있어요)
이 폴더 안의 electron.exe 로 등록되므로, 폴더를 옮기면 옮긴 곳에서 한 번 켜 주면 다시 등록돼요.

## 버전별로 쓰는 법

| 어디서 | 어떻게 | 상태 |
| --- | --- | --- |
| 윈도우 PC | `npm start` (바탕화면·시작 메뉴 바로가기) | 매일 쓰는 중 |
| 맥 | 맥에서 `npm install` → `npm start` | 코드만 맞춰 둠, 맥에서 아직 안 켜 봄 |
| 안드로이드 | `npm run android` → `mobile/ai-assistant.apk` 를 폰에 깔기 | 에뮬레이터에서 확인 |
| 아이폰 | 사파리로 https://ai-biseo-mocha.vercel.app → 공유 → 홈 화면에 추가 | 올려 둠, 진짜 아이폰에선 아직 |

### 맥
- 캐릭터·말풍선·체크메이트·알람·날씨·AI 는 윈도우와 똑같아요.
- 다른 점: 🎤 는 맥 받아쓰기(fn 두 번)를 안내만 해요. "○○ 열어줘"는 응용 프로그램 폴더의 앱을 열어요.
- 집중 지킴이는 처음에 '손쉬운 사용' 권한을 물어볼 수 있어요 (창 제목을 보려고).
- 로그인할 때 자동 실행: `~/Library/LaunchAgents/com.aibiseo.assistant.plist`.

### 폰 (안드로이드 · 아이폰 공통)
- 폰 화면은 PC 화면 파일(renderer/)을 그대로 쓰고, 두뇌만 `mobile/web/backend.js` 로 새로 만들었어요.
- `npm run mobile:build` → `mobile/www` 에 폰용 파일이 생겨요. `npm run mobile:serve` 로 이 컴퓨터에서 미리 보기 (http://localhost:5178).
- 설정·키·로그인은 그 폰 안(앱 저장소)에만 저장돼요.

### 안드로이드
- 앱을 열면 캐릭터 + 위쪽 버튼(🫧 띄우기, 📅 오늘, 💬 물어보기, ⚙️ 설정).
- 🫧 를 누르면 **다른 앱 위에 캐릭터가 떠 있어요**. 처음엔 '다른 앱 위에 표시' 허락이 필요해요.
  끌어서 옮기고, 누르면 앱 설정이 열려요. 말풍선이 뜰 때만 창이 커지고 나머지 화면은 그대로 눌려요.
- 알람·타이머는 폰 알람으로도 맡겨서 앱이 꺼져 있어도 울려요. 일정 알림은 폰 알림으로도 와요.
- 🎤 는 폰 음성 입력, 🔊 는 폰 읽어 주기. "카톡 열어줘"는 폰에 깔린 앱을 열어요.
- 설정 → 기타 → '폰 켤 때 캐릭터 띄우기'.
- 빌드: 안드로이드 스튜디오에 들어 있는 자바·그래들을 써요. 빌드 도구가 한글 경로를 못 읽어서 `build-android.ps1` 이 잠깐 영어 드라이브 글자(subst)로 옮겨서 빌드해요.
- 폰에 깔기: APK 파일을 폰으로 옮겨서 열기 (출처를 알 수 없는 앱 설치 허용 필요). 또는 USB 연결 후 `adb install mobile/ai-assistant.apk`.

### 아이폰
- 애플은 다른 앱 위에 떠 있는 걸 막아서, **홈 화면 웹앱**으로 써요. 앱 화면 안에서 캐릭터·카드·물어보기·설정은 다 돼요.
- 주소: **https://ai-biseo-mocha.vercel.app** (Vercel 의 ai-biseo 프로젝트). 사파리로 열고 공유 → **홈 화면에 추가**.
- 고친 걸 다시 올리기: `npm run mobile:deploy` (이 컴퓨터 이름이 한글이라 Vercel 도구가 멈추는 걸 `mobile/hostfix.cjs` 로 피해 가요).
- 홈 화면에서 연 뒤 🔔 알림 켜기를 누르면 알림을 받을 수 있어요. 알람은 앱을 열어 둬야 정확히 울려요.
- 앱 열기("카톡 열어줘")는 아이폰이 막아서 못 해요. 검색은 돼요.

## 사용법

| 동작 | 하는 일 |
| --- | --- |
| 누르기 | 설정 창 |
| 꾹 누르기 | 애교 (계속 누르면 다음 애교) |
| 끌기 | 옮기기 (흔들면 어지러워해요) |
| 커서로 문지르기 | 쓰다듬기 💕 |
| 마우스 휠 | 캐릭터 크기 |
| 우클릭 | 빠른 메뉴 (📸 화면 봐 줘 포함) |
| Ctrl+Shift+Space | 어디서든 물어보기 창 |

1분 동안 아무것도 안 하면 잠들고, 커서를 움직이면 깨요.

## 기능

- **체크메이트 일정**: 설정 → 로그인. 일정 10분 전·정각, 할 일 알림 시간에 알려 줘요. 읽기만 해요.
  - `checkmate.config.json`: 체크메이트 서버 주소와 공개(publishable) 키. 비밀 키 아님.
  - 로그인 토큰은 윈도우 계정으로 암호화해 저장 (비밀번호는 저장 안 함).
- **오늘의 할 일 카드**: 진행률, 일정 타임라인(진행 중·다음 일정), 목표 색 체크리스트.
- **집중 타이머**: 25분 집중 → 5분 휴식 (45분 넘게 집중하면 10분).
- **건강 알림**: 물(1시간), 스트레칭(50분), 눈 쉬기(20분). 집중 중이거나 자리를 비우면 쉬어요.
- **물어보기**: 시간·날짜·오늘 할 일·타이머·"30분 뒤에 빨래 알려줘"·계산·검색(네이버/구글/유튜브).
  - 🎤 버튼: 윈도우 기본 음성 입력(Win+H)을 열어서 말로 입력. 말이 끝나면 자동으로 보내요.
  - 🔊 버튼: 대답을 윈도우 한국어 목소리로 읽어 줘요.
  - "카톡 열어줘", "크롬 켜", "유튜브 틀어줘": 시작 메뉴에 있는 앱이나 자주 가는 사이트를 열어요.
  - "7시에 알람", "내일 아침 7시에 깨워줘", "오후 3시 반에 학원 알려줘", "알람 뭐 있어", "알람 다 꺼"
  - 알람·예약 알림은 저장돼서 비서를 껐다 켜도 남아요. 울릴 때 소리 + "5분 뒤" 버튼.
    (비서가 꺼져 있는 동안은 못 울려요. 켤 때 10분 안에 지나간 알람은 바로 울려요)
- **위키백과 대답** (AI 키 없이): "블랙홀이 뭐야", "세종대왕 누구야", "광합성 뜻", "임진왜란에 대해 알려줘".
  한국어 위키백과 요약을 한두 문장으로. AI 를 연결해 두면 AI 가 대신 대답해요. 보내는 건 물어본 낱말뿐.
- **📸 화면 봐 주기** (PC, AI 연결 필요): 물어보기 창의 📸 → **어디를**(🖥️ 전체 · 🪟 지금 창 · ✂️ 영역) + **무엇을**(✨ 알아서 · 🔍 설명 · ✏️ 문제 풀이 · 🌐 번역 · 🐞 오류 해결 · 📝 요약).
  - 말로도 돼요: "이 문제 풀어줘", "이 오류 뭐야", "화면 번역해줘", "이 부분만 요약해줘"(→ 영역 고르기), "지금 창 설명해줘".
  - 우클릭 메뉴 → 📸 화면 봐 줘 / ✂️ 영역 골라서 물어보기. 영역은 마우스나 손가락으로 끌어서 고른 뒤 **✅ 이 부분 물어보기**(또는 Enter·네모 안 두 번 누르기). ↺ 다시 / ✕ 취소 / 🖥️ 화면 전체 버튼도 있어서 태블릿 모드에서도 돼요.
  - 원본 해상도로 찍고 AI 에게는 긴 쪽 2576px(3.75MP)까지 보내요. Claude 는 작은 글자가 흐리면 그 부분을 **스스로 확대(🔎)** 해서 다시 봐요.
  - 모드마다 안내가 달라요: 풀이는 "답:" + 단계 + 검산, 오류는 원인 + 해결 단계, 번역은 구조 유지 + 어려운 단어 풀이, 요약은 한 줄 + 핵심 목록.
  - 대답 뒤 3분 안에 이어서 물어보면("2번은?", "더 쉽게") 같은 화면을 보고 대답해요. 물어보기 창을 닫으면 잊어요.
  - 찍는 순간 비서 창은 숨겨요. 사진은 파일로 저장하지 않고 고른 AI 에게만 보내요. Claude 로 한 번에 대략 Haiku 1~3원, Opus 30~80원 (확대를 많이 하면 조금 더).
  - 맥은 처음에 '화면 기록' 권한을 허락해야 해요. 폰은 다른 앱 화면을 찍을 수 없어서 안 돼요.
- **🍅 집중 시간 고르기**: 설정의 '집중 시간 (분)' 칸(15·25·30·45·60·90), 우클릭 메뉴 → 🍅 집중하기, 말로 "집중 시간 45분으로 바꿔줘". "집중 시작"은 고른 시간으로, "50분 집중"은 이번만. 쉬는 시간은 45분 미만 5분 · 80분 미만 10분 · 그 이상 15분.
- **🏫 학교 급식·시간표 (나이스)**: 설정 → 학교에서 학교 이름으로 찾고 학년·반 고르기.
  - "오늘 점심 뭐야", "내일 급식", "석식 메뉴", "시간표 알려줘", "다음 수업 뭐야", "3교시 뭐야".
  - 아침 브리핑에 오늘 수업·점심 메뉴, 켜 두면 수업 5분 전 알림과 점심시간 메뉴 알림 (1교시 시작·수업 길이는 설정에서).
  - 인증키 없이도 되지만 나이스가 5줄까지만 줘서 시간표는 5교시까지 보여요. open.neis.go.kr 무료 인증키를 넣으면 7교시까지.
- **📌 화면 → 할 일**: 📸 → 📌 할 일로 (또는 "이 공지 할 일로 넣어줘"). 공지·과제 화면에서 마감을 찾아 목록으로 보여 주고, 고른 것만 체크메이트에 넣어요. 마감 하루 전 저녁 8시 알림.
- **📊 집중 기록·주간 리포트**: 집중을 시작할 때 오늘 할 일 중 하나를 고르면 그 목표(과목)로 시간을 모아요. 끝나면 "끝냈어?" → 체크메이트 완료. "이번 주 공부 얼마나 했어" / "주간 리포트" → 요일 막대·과목별 시간·지난주 비교. 기록은 이 컴퓨터에만.
- **🔌 다른 AI 앱과 연결 (Claude 데스크톱)**: 설정 → 다른 AI 앱과 연결 → 연결하기 → Claude 앱을 트레이에서 완전히 종료했다가 다시 켜기.
  - Claude 앱 대화에서 비서를 도구로 써요: 오늘 일정·할 일 읽기, 체크메이트 할 일 추가·완료·내일로·이름 바꾸기·지우기, 집중·타이머 켜고 끄기, 알림·알람 맞추고 지우기, 캐릭터 말풍선 띄우기.
  - 다른 AI 가 한 일은 캐릭터 말풍선에 "○○에서 부탁했어"로 떠요. 비서가 켜져 있어야 해요.
  - 안전: 이 컴퓨터 안(127.0.0.1)에서만, 켤 때마다 바뀌는 비밀 토큰이 있어야만 열리고, 웹페이지에서 오는 요청은 막아요. Claude 설정 파일은 ai-biseo 한 줄만 넣고 빼며 .bak 을 남겨요.
- **🌐 ChatGPT·Claude 웹/폰에서 부르기 (원격)**: 설정 → 다른 AI 앱과 연결 → "ChatGPT·폰에서 부르기" 켜기 → 주소 `https://ai-biseo-mocha.vercel.app/mcp` 를 ChatGPT·Claude 의 커스텀 커넥터에 넣고 체크메이트 계정으로 로그인.
  - 할 일 보기·넣기·완료는 PC 가 꺼져 있어도 돼요(체크메이트에 바로). 집중·타이머·알림·말풍선은 PC 비서가 켜져 있을 때.
  - 구조: Vercel 함수(`mobile/server/api`: OAuth 로그인 + MCP) → 체크메이트 Supabase 실시간 채널 → PC(`lib/remote.js`). 채널 이름은 무작위로 만들어 체크메이트 계정 정보(user_metadata)에만 적어 둬요. 체크메이트 표는 하나도 안 바꿔요.
  - 서버 비밀값은 Vercel 환경 변수 `AIBISEO_SECRET` (로그인 토큰을 암호화). "원격 연결 끊고 새로 만들기"를 누르면 채널이 바뀌어 예전 연결은 PC 에 부탁할 수 없어요.
  - Claude Code 에서도 쓰려면: `claude mcp add ai-biseo -- node "<이 폴더>/mcp/aibiseo-mcp.js"`
- **캐릭터 키우기**: 할 일 하나 끝 +10 XP (체크메이트 앱에서 끝내도 쳐 줘요), 집중 한 번 끝 +20, 하루 첫 출석 +5.
  레벨이 오르면 꾸미기 아이템이 생겨요: 🎀 리본(Lv.2) · 🌸 꽃핀(3) · 👓 안경(4) · 👑 왕관(5) · ⭐ 별 머리핀(6) · 🧣 목도리(7) · 😇 천사 링(8).
  설정 → 꾸미기에서 바꾸기. 레벨은 PC 와 폰이 따로 쌓여요.
- **날씨**: "날씨 어때", "내일 날씨", "우산 필요해?". Open-Meteo(무료, 키 없음). 동네는 설정에서 (기본 서울).
- **아침 브리핑**: 아침(5~12시)에 처음 컴퓨터를 쓸 때 날씨·미세먼지·오늘 일정·할 일·D-day·알람을 한 장으로.
- **비 알림**: 두 시간 안에 비가 오면 하루 한 번 알려줘요.
- **집중 지킴이**: 집중 타이머 중에 유튜브·넷플릭스·인스타·게임 같은 창을 6초 넘게 보면 캐릭터가 째려보며 말려요.
  공부 영상(강의·인강·EBS 등 제목)은 봐 줘요. 창 제목은 이 컴퓨터 밖으로 보내지 않아요.
- **AI 연결** (설정 → AI 연결): 물어보기에서 비서가 직접 못 하는 질문을 AI 가 대답해요.
  - 제미나이(무료): https://aistudio.google.com/apikey 에서 키를 받아 붙여 넣기. 키로 쓸 수 있는 가장 새 Flash 모델을 자동으로 골라요.
  - Claude(유료): Anthropic 콘솔에서 받은 `sk-ant-…` 키. 모델은 Opus(기본)·Sonnet·Haiku 중 고르기.
    거절된 질문은 다른 Claude 모델로 자동 재시도(server-side fallback)하도록 켜 뒀어요.
  - 둘 다 필요하면 구글/웹 검색을 같이 써서 최신 정보도 대답해요.
  - 키는 윈도우 계정으로 암호화해서 저장. 질문과 대화 내용만 고른 AI 회사로 보내요 (체크메이트 할 일은 안 보내요).

## 어디서 돌아가요?

전부 이 컴퓨터에서 돌아가요 (Electron 앱). 따로 서버는 없어요.
인터넷으로 나가는 건 이것뿐이에요:
- 체크메이트 서버(Supabase): 로그인했을 때 일정·할 일 읽기
- 제미나이 또는 Claude: 물어보기에서 AI 에게 넘긴 질문 (📸 를 쓰면 그때 찍은 화면 사진 한 장도)
- 검색 버튼: 브라우저로 네이버·구글·유튜브 열기
- 날씨(Open-Meteo): 설정한 동네의 위도·경도

## 캐릭터

- 3D 캐릭터 10종: 하늘냥, 분홍토끼, 곰돌이, 삐약이, 찹쌀떡, 펭귄, 개굴이, 멍멍이, 판다, 햄찌
- `characters/` 폴더에 PNG·GIF 등을 넣으면 그림 캐릭터로도 쓸 수 있어요.
- 저작권 있는 캐릭터(예: 치이카와)는 혼자 쓰는 용도로만. 남에게 배포할 땐 빼기.
